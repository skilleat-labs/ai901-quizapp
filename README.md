# AI-901 클래스룸

교안 이론 블록 직후 문제를 풀고, 성적·순위·해설을 확인하는 수업용 웹앱입니다. 학생은 기수를 선택하고 이름만 입력합니다. 기존 `skillshop/labs/`와 별개이며 이 폴더가 퀴즈 앱 전용 Git 저장소 루트입니다.

## 로컬 실행

Node.js 24 이상에서 이 폴더를 터미널로 열고 실행합니다.

```sh
npm ci --ignore-scripts
npm run setup
npm start
```

학생: http://127.0.0.1:3100 · 강사: http://127.0.0.1:3100/admin

`setup`이 생성한 `.env`의 `ADMIN_PASSWORD`가 강사 암호입니다. `.env`는 Git에서 제외됩니다. 이미 있으면 덮어쓰지 않습니다. 로컬 기록은 `.data/`에 보관되며 개발용 단일 프로세스만 지원합니다.

## 수업 진행

1. 강사 화면에서 기수를 만들고 학생 입장 링크를 복사합니다. 기본 기수는 `ai901`입니다.
2. 이론 수업 후 해당 평가를 열고 제한 시간과 해설 공개 시점을 선택합니다.
3. 학생이 이름을 입력하고 풀이합니다. 답안은 자동 저장되며 재접속하면 이어서 풀 수 있습니다.
4. 제출 후 정답률·공동 순위·보기별 해설·공식 근거 링크를 확인합니다. 마감 후 공개를 선택하면 그때까지 세부 채점도 숨깁니다.
5. 강사는 오답 분석으로 보충 설명하고, 학생별 기록을 CSV로 내려받을 수 있습니다.

학생 이름은 해당 기수 순위에 표시됩니다. 같은 기수에서 같은 이름을 입력하면 기존 기록에 연결됩니다. 본인 인증은 없으므로 동명이인은 `김민수A`, `김민수B`처럼 구분해서 안내하세요.

## 평가와 순위 규칙

- 일차별 2세트씩 8세트 × 20문항, 종합 모의고사 2세트 × 40문항: 고유 문항 총 240개. 여기에 응용 은행을 재구성한 **최종 모의고사 3세트 × 45문항**을 추가했습니다. 최종 3세트 간 동일 문항은 겹치지 않으며, 기본 시간은 각 50분입니다.
- 정규는 기초·상황 연습, 모의고사는 요구사항 판단·코드 해석으로 보강한 자체 제작 문항입니다. Microsoft 실제 시험 문제나 공식 연습평가 복제본이 아닙니다.
- 서버에서 채점합니다. 복수 선택은 정답을 모두 선택하고 오답을 고르지 않아야 득점합니다. 실제 시험의 환산 점수·부분점수와 다릅니다.
- 세트 공식 응시는 최초 1회이며, 재풀이는 복습 기록으로 남고 순위에서 제외됩니다.
- 누적 순위는 정규 8세트별 가장 먼저 시작한 공식 응시의 정답률 합계(최대 800)입니다. 모의고사는 별도 회차 순위로 확인합니다. 동점은 공동 순위(1, 1, 3)입니다.
- 제한 시간 종료 또는 강사 마감 시 마지막 저장 답안으로 확정합니다. 네트워크가 끊긴 동안의 미저장 답안은 복원되지 않습니다.
- 강사는 회차별 문항을 채점 제외할 수 있으며 점수와 순위가 다시 계산됩니다.
- 학생 홈 순위는 15초 간격으로 갱신합니다. 강사 화면은 새로고침 버튼으로 갱신합니다.
