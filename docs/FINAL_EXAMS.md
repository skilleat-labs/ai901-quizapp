# 최종 모의고사 3회 · 편성표

개정된 응용 문항을 재구성한 45문항 × 3회입니다. 새로운 135문항을 별도 집필한 것은 아닙니다. 기존 수업·종합 문제와 중복되지만 최종 3회 사이에는 동일 문항 ID가 겹치지 않습니다. 같은 주제의 다른 상황은 포함될 수 있습니다.

각 50분(강사 개방 시 변경 가능), 개념 19 / 구현 26. 실제 시험의 문항 수·시간·난이도와 동일하다는 뜻은 아닙니다. 사이트는 응시자마다 문제·보기 순서를 다시 섞습니다.
