# 문항 표현 개정 · 2026-10-25

고유 문항 240개를 버전 3으로 개정했습니다. 기본·종합·최종 13세트 모두 개정 은행을 사용합니다.

- 수업별 160개 질문을 완결된 문장으로 다시 편집했습니다. 모의고사도 질문·보기의 의미가 어긋난 부분과 단일/복수 질문이 중복된 부분을 수정했습니다.
- 핵심 용어에 한글(영문)을 병기했습니다. 질문·보기·해설에 같은 용어표를 적용하며 Python 코드와 API 식별자는 원형을 유지했습니다. 전체 문장의 영어 번역본은 아닙니다.
- 배경 상황과 질문을 문단으로 나누었습니다. 기능을 물으면서 결과를 답으로 제시하던 문항 등 응답 수준을 맞추었습니다.
- 긴 한영 표현과 코드의 줄바꿈·최소 너비를 조정했습니다. 다음/이전/번호 이동 때 맨 위로 이동하고 질문에 초점을 줍니다. 답 선택 때 전체 화면을 재생성하지 않아 읽던 위치와 입력 초점을 보존합니다.
- 인쇄용 최종 3회 문제·해설을 함께 다시 생성했습니다.

브라우저에서 질문·보기·코드를 표시하고 다음 문항 이동 후 scrollY=0, 가로 넘침 없음, 선택한 입력의 초점 유지를 확인했습니다. 모바일 실기기에서 검증한 결과는 아닙니다.

로컬 3100 서버의 신규 응시 은행에도 적용했습니다. 과거 점수와 진행 중 응시는 시작 당시 스냅샷을 유지하므로 이전 표현이 남을 수 있습니다. 최신 문항은 새 평가 회차 또는 새로 시작한 응시에서 확인합니다. 기존 기록 삭제나 소급 재채점은 하지 않았습니다.

표현 개선이 공식 시험과 같은 난이도·출제를 보장하는 것은 아닙니다. 용어표는 TERM_GLOSSARY.csv, 편집 원고는 scripts/polish_language.py입니다.
