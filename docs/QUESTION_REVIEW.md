## 공식 문제와의 관계

사이트 문항은 자체 제작이며 공식 시험·Practice Assessment 원문 복제본이 아닙니다. 공개 모듈 평가를 참고해 학습 목표와 구현 구분을 대조했습니다. 정답 해설의 “Learn 공식 지식 점검”은 Microsoft 사이트 원문으로 이동하는 링크입니다. 자체 문제의 정답이 공식 채점으로 검증됐다는 뜻이 아닙니다.

공식 시험 연습평가 전체는 열람·수집하지 않았습니다. 공식 가이드는 AI Skills Navigator에 로그인해 평가를 시작하도록 안내합니다. 범위 근거: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-901

공개 모듈 확인: 생성형 AI 개념, 생성형 AI·에이전트 구현, 텍스트 분석, Speech 구현, 비전·이미지 생성, 정보 추출 평가. 세부 문항별 근거와 연결 모듈은 `question-coverage.csv`를 참조하세요.

## 적용과 기록 보존

저장소에 가져온 문제은행이 없다면 새 실행은 코드의 개정 은행을 사용합니다. 강사 화면에서 이전 JSON을 가져온 적이 있다면 **문제은행 → 개정 content/questions.json 선택 → 검증 후 적용**이 필요합니다. 이전에 시작한 응시는 스냅샷을 유지하므로 새 평가를 열고 새로 시작해 확인하세요. 과거 기록을 삭제하거나 점수를 소급 변경하지 않았습니다.
